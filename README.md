# Reduck official script library

905 browser automations, one markdown document each, for the sites people actually use —
LinkedIn, Instagram, Slack, Amazon, SNCF Connect and hundreds more.

A **script** is one task on one site, addressed as `@reduck/<site>/<slug>`. It drives the real
page, so it works where there is no API and behind a login, and it answers JSON matching a declared
output schema. Each document here says what a script takes and what it returns.

## Get started

**[reduck.ai](https://reduck.ai)** — an AI agent runs these for you, in your own
Chrome where you are already signed in, or in a Reduck-hosted browser.

- [Browse every script](https://reduck.ai/explore/scripts)
- [Docs](https://docs.reduck.ai)

## What is here

- `scripts/<site>/<slug>.md` — one document per script.
- `index.json` — every script with its address and its page.
